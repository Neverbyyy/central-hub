# apps/landings — лендинги на Nuxt 4

Одно приложение, лендинги по путям: `/cars2`, `/farm` (английский), `/<путь>/<язык>`. Образцы: `cars2` — по макету
Антона, `farm` — без макета, из тех же блоков, `cars2-go` — свой дизайн и живая страница (`config.road`, тема `cars2-go`); значки сторов и логотип — общие (`app/shared/art`). Все страницы собираются заранее
(prerender) — на Vercel это статичный HTML. Дизайн-система подключена модулем `@amaya/nuxt` одной строкой.

- Лендинг — папка `app/landings/<путь>/`: `config.ts` и `art/` (картинки по конвенции, ролик, `.riv`). Конфиг — `defineLanding`
  из `app/shared/landing.ts`: своё (тема, сторы, преимущества, арт, число отзывов и вопросов) задаёт лендинг, общее
  (значки, логотип, футер, ключи мета-тегов и первого экрана) — там. `app/shared` лежит вне `app/landings`: каждая папка
  там — лендинг. Реестр (`app/landings/index.ts`) и история в Storybook находят папку сами. Страницы для сборки nuxt.config
  находит по папкам, языки — по файлам `packages/locales/src`.
- Страница — `app/pages/[landing]/[[lang]].vue`: 404 для неизвестного, `await useLocale(lang)` (только язык страницы),
  мета-теги из ключей, noindex. `app/pages/index.vue` — оглавление стенда (лендинги, выбор языка, «Открыть») для команды:
  служебная, без правил дизайн-системы; новый лендинг появляется в нём сам — править её не нужно.
- Стенд — https://landings-six-henna.vercel.app (сборка из `main`).
- Тексты — ключи сервиса (`web.<сайт>.*`); пока ключи не утверждены, в собранной странице видны сами ключи —
  утверждение и выгрузка (набор `ds`) — за человеком.
- Проверка: `pnpm --filter @amaya/landings dev` (3020), сборка — `pnpm turbo run build --filter=@amaya/landings`,
  проверки в браузере по всем лендингам — `pnpm --filter @amaya/landings check` (после сборки),
  Lighthouse — по собранной статике `.output/public` (мобильный: LCP < 2,5 с, CLS ≈ 0).
- Арт — только webp и только то, чего нет в `packages/art`: PNG и копии ловит `tools/check-art.mjs`.
- Линтер — Nuxt плюс правила дизайн-системы (`tools/eslint/rules.mjs`).
