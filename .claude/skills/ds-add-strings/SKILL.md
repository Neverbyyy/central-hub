# Добавить строки

Строк в коде нет — только ключи. Тексты живут в сервисе (MCP `amaya-hub`), в код попадают выгрузкой.

1. **Найти похожие:** `find_similar` (английский текст и предполагаемый ключ). Смысл тот же — бери существующий ключ
   (`common.button.continue.default`, `common.link.terms_of_use`…). Текст совпал, а смысл другой — новый ключ.
   Похожие нашлись только в `legacy.*` (капс, `<br/>`, старые цифры) — новый ключ по схеме, переводы можно взять оттуда,
   приведя к правилам. Фраза общая для нескольких игр (легаси показывает её у dino, farm, cars…) — `common.<раздел>.*`;
   только про эту игру — `app.<игра>.*`.
2. **Ключ по схеме** (от общего к частному, `snake_case`, без языка и вёрстки в имени):
   `common.` — одинаковое везде; `app.<игра>.` — экраны игры; `web.<сайт>.` — лендинги; `ds.<компонент>.` — подписи
   компонентов дизайн-системы; `test.<тест>.<обычный ключ>`. Коды игр и сайтов — `list_registry`. Шаги — группой:
   `onboarding.step_1.title`. Ключ не может быть началом другого.
3. **Создать:** `create_key` — английский текст, обязательное описание (где показывается, сколько места, ограничения),
   `max_length`, теги — только существующие (`list_registry`, `kind: tag`; новые теги создают люди в сервисе).
   Подстановки — по имени (`{price}`), множественное число — через `|`, `@ { } | $` экранировать
   (`{'@'}`), без HTML, обычный регистр (капс делает тема).
4. **Переводы:** `write_draft_translation` на ru, de, es, it, pt, fr, sv, nl — статус «от ИИ». Французский — неразрывный
   пробел перед `! ? : ;`. Длину проверить: `check_text`.
5. **В коде:** `t('web.lp_cars2.hero.title')` в экране или блоке; компонент получает уже переведённый текст пропсом.

Утверждает тексты и выгружает их в код (набор `ds` → `packages/locales`) человек. До этого в собранной странице
видны ключи; в Storybook для проверки можно подставить черновики перехватом запроса к `packages/locales/src/<язык>.json`.
Пачку ключей удобнее завести скриптом через MCP-клиент (`@modelcontextprotocol/sdk`, токен `AMAYA_HUB_TOKEN`).
