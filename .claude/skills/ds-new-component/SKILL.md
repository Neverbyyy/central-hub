# Новый компонент

Сначала — точно ли он нужен: перечитай `packages/ui/manifest.md`. Часто хватает пропа, варианта или токена темы
у существующего компонента. Компонент делается под настоящий экран, а не «на будущее».

1. **Файл** `packages/ui/src/components/Ds<Имя>.vue`, `<script setup lang="ts">`, API Vue 3.3 (`withDefaults(defineProps…)`,
   без defineModel/useTemplateRef/useId/деструктуризации). Имя в Figma — `<Имя>` без Ds.
2. **JSDoc** в начале скрипта: что это; «Когда использовать: …»; вид — какие токены; поведение. `//` над каждым
   неочевидным пропом. Из этого строится манифест.
3. **Тексты снаружи** — пропсы/слоты, подписи для скринридера — пропсом (ключ `ds.<компонент>.*`, скилл `ds-add-strings`).
   Компонент не переводит, не шлёт аналитику (только событие), не знает про InApp.
4. **Только токены**: классы `ds:`; нет токена — добавить в `packages/tokens` (base + темы), значение из Figma.
5. **Отклик**: нажимаемое — `usePressed` (`data-pressed`), `useTapGuard`, зона ≥ 44; анимация — только transform/opacity,
   `--ds-duration-*`; тяжёлое — по требованию.
6. **Экспорт** в `packages/ui/src/index.ts`, типы — в `src/types.ts`.
7. **История** рядом: `Ds<Имя>.stories.ts`, раздел по месту использования («Общее», «Cars 2», «Farm», «Блоки лендинга»),
   все состояния, тексты — ключами (`useStoryTexts`), длинный текст — немецким из тулбара. Порядок раздела —
   `storySort` в `apps/storybook/.storybook/preview.ts`.
8. **Манифест**: `pnpm --filter @amaya/ui manifest`.
9. **Проверка**: скилл `ds-self-check`.
